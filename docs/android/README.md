## ★ 見張り役の起こし方（セッションを跨いだら）

`anydesk-gate.sh` は **起動したセッションに属します。**セッションが終われば止まります。

```bash
# 起こす
nohup ~/dotfiles/scripts/android/anydesk-gate.sh >/dev/null 2>&1 &

# 生きているか
pgrep -f 'bash .*anydesk-gate.sh' && tail -3 ~/.android-lab/gate.log

# 止める
pkill -f 'bash .*anydesk-gate.sh'

# 解除だけ試す
~/dotfiles/scripts/android/anydesk-gate.sh --test-unlock
```

★ **止まると失われるもの**: ロックされている時の自動解除 ／ 画面共有の確認を通すこと ／
共有するアプリに LINE を選ぶこと ／ 接続終了後の自動ロック。
★ **止まっても残るもの**: 接続そのもの（無人アクセス）と、操作できること。

## 無線デバッグが切れた時（2026-09-12 追記・2026-09-13 原因を訂正）

端末の無線デバッグは、端末の Wi-Fi が切れた時と、繋ぐ親機が変わった時に、Android が自動で OFF にする。
2026-09-13 23:39 に端末の記録で直接見た（別の網へ移った 0.15 秒後に OFF）。
前の版は「再起動などで OFF に戻る」と書いていたが、2026-09-10〜13 の 4 回はどれも再起動ではなかった
（端末の稼働 11 日）。4 回とも、端末の Wi-Fi の出来事と数秒以内で重なっている。

```
9/10 11:18  親機側から切断（5GHz・5620MHz）
9/12 12:40  同じ網のまま 5GHz から 2.4GHz へ移った（電波が弱い時）
9/12 22:47  親機側から切断（5GHz・5620MHz）
9/13 23:39  別の網へ移った
```

2026-09-10 の時は、見張り役は動いたまま 2 日間 端末を掴めなかった（adb は古い口へ繋ぎ直そうとするだけで、新しい口を探さない）。

- 直し方: 端末で 設定 → 開発者オプション → ワイヤレス デバッグ を ON にするだけ
  （家の網は「常に許可」済み。ただし覚えているのは親機 1 台分だけで、別の親機では確認が出る。
  main03 は「ペア設定済みのデバイス」に居る）
- 2026-09-13 の手当て（剛さま裁定）: 端末が自分で網を移らないようにした。
  「より最適な Wi-Fi ネットワークに切り替え」を OFF、家で届く他の 2 つの網の「自動再接続」を OFF（sagyou-log 操作 12）。
  親機側から切られる分（5620MHz の 2 回）はこれでは止まらない。5620MHz は気象レーダーと共用の帯で、
  親機が自分でチャンネルを移すことがある（親機の記録は見ていない）
- 2026-09-12 から、見張り役は端末を掴めない間、台帳のアドレスで adb の口を探して自分で繋ぎ直す
  （`scripts/android/find-adb-port.py`。探す間隔は 1 分から倍々に 8 分まで）。
  同日 01:56 に、ON にされた直後に自分で繋ぎ直したことを記録で確かめた
- 見張り役の記録に「無線の口が見つからない」が出ていたら、端末の無線デバッグが OFF の合図
